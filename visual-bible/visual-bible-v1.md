# Visual Bible v1 — 《自我的彼岸 / The Other Side of Self》

> 版本：`v1`
> 适用范围：第三阶段 Visual Bible 与视觉基准系统（图片 / 视频生成）。
> 本文件是艺术方向的总纲；机器可读的等价配置见 `palette.json` 与 `style-profile.json`，生图提示词模板见 `prompt-templates/`。

## 1. 艺术方向

《自我的彼岸》是一场关于"理想自我"的沉浸式艺术体验。观众在第二阶段（Imagine）通过对话描述自己向往的生活、环境与感受；第三阶段把这些**已确认**的意图转化为图像与动态影像。

核心气质：

- **沉浸（Immersive）**：观众不是"看图"，而是"走入"一个被理解的、缓慢呼吸的世界。
- **克制（Restrained）**：少即是多。不堆砌元素，不喧哗。
- **诗意（Poetic）**：以暗示代替说明，留白大于填满。
- **空间感（Spatial）**：强调纵深、空气与尺度，让画面"能呼吸"。
- **缓慢变化（Slow-changing）**：静态图与动态影像都不应有突兀的剪辑或快速运动；变化如潮水般缓慢。

## 2. 色彩（集中维护于 `palette.json`）

基准色板（禁止在组件或提示词中散落硬编码色值，统一引用 `palette.json`）：

- **深海蓝 `#04222E`** — 背景基底、深邃空间、夜与水的深处。
- **青绿 `#0E5A57`** — 中景植被、水色、过渡层次。
- **柔和青蓝 `#8EDBE4`** — 光线、高光、视觉焦点、希望感。
- **暖白 `#F4EFE6`** — 人、织物、微光、温度。

色彩纪律：

- 整体保持低饱和、低对比的"水下/晨雾"质感。
- 允许在柔和青蓝与暖白之间做细微偏移，但**不允许高饱和撞色**。
- 禁止纯黑作为主色；暗部应是深海蓝的延伸。

## 3. 光线、构图、空间深度、材质、人物

- **光线**：柔和的侧逆光或漫射天光；避免硬阴影与舞台式聚光。光是"被理解的温柔"，不是戏剧打光。
- **构图**：三分法或中心留白；主体偏小、环境偏大，给观众"身处其中"的空间感。避免居中对称式商业海报构图。
- **空间深度**：近景（柔焦人物/手部/物件）— 中景（环境氛围）— 远景（海平线 / 林线 / 天光）三层纵深。
- **材质**：棉麻、未抛光的木、石、水面、雾、织物；拒绝金属高光塑料感与玻璃幕墙式炫光。
- **人物表现**：人物通常背影、侧影或局部（手、肩、发），**不露脸特写**；人物是"观众的投射"，不是模特摆拍。

## 4. 图片与视频的镜头和动态原则

- **镜头**：多用固定长镜或极缓慢的推拉；避免快速摇移、变焦、手持抖动。
- **动态（视频）**：环境微动（水波、雾流、光影缓移）为主；人物动作极缓；循环（loop）必须无缝。
- **节奏**：单段建议 8–16 秒，整体缓慢；变化幅度小。

## 5. 固定美学规则与允许变化的场景参数

**固定（不可被用户个性化覆盖）**：上述色彩纪律、光线气质、构图留白、人物不露脸、缓慢变化、克制留白。

**允许变化（由观众意图驱动）**：场景地点（海边/森林/家/未来城市等）、具体活动、一天中的时刻、是否有人物、物件细节、冷暖微调。

> 固定规则与个性化场景在提示词模板中严格分离：见 `prompt-templates/image-master.md` 的 `{{...}}` 变量区与"固定美学规则"区。

## 6. 禁止事项

- 不必要的文字、标语、Logo、UI 叠加。
- 商业广告式构图（居中大字、强销售感、过度锐利）。
- 过度饱和、霓虹色、赛博朋克高对比。
- 无意义的光效堆叠（光剑、爆炸、粒子洪流）。
- 将观众心理推断当作事实强行视觉化（例如把"可能渴望自由"画成破碎锁链）。

## 7. 版本管理

- Visual Bible 版本号见 `palette.json` 与 `style-profile.json` 的 `version` 字段，与 `visual_bible_version` 对齐。
- 任何美学变更都升小版本（v1 → v1.1），并在本文件追加变更记录。
- 生图提示词模板 `prompt_version` 与 Visual Bible 版本独立管理；World Brief 中记录二者以便复现。
